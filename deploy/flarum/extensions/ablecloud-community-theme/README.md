# ABLESTACK Community Theme

Flarum Core를 수정하지 않고 ABLESTACK Community의 화면과 한글 사용성을 개선하는 전용 테마 확장입니다.

- ABLESTACK 색상·간격·타이포그래피 적용
- 블루 계열 Hero·배경·카드 경계와 충분한 본문 내부 여백 적용
- 로고보다 작은 타이틀과 압축된 Hero 높이로 콘텐츠 공간 확보
- 280px 카테고리 메뉴와 태그 페이지 버튼 넘침 방지
- 태그 도구 모음 버튼의 좌우 16px 균등 여백, 아이콘·글자 중앙 정렬, 하단 선택 표시
- 태그 목록을 여백 있는 카드 Grid로 전환하고 최근 토론을 독립 패널로 구분
- 보조 태그를 별도 구역으로 나누고 각 태그의 설명 정보를 카드에 표시
- 최근 토론의 절대 날짜는 `00년 0월 0일`로 표시하고 `0일 전` 같은 상대 날짜는 유지
- Flarum 의미 클래스는 유지하되 공통 내장 SVG 아이콘으로 표시하여 웹폰트 로딩 실패 시 점·더하기·깨진 사각형 방지
- 연구소 배지·토론 타임라인·댓글 수·설정 알림·작성기 작업·검색 초기화까지 전 화면 SVG 아이콘 매핑 적용
- 토론 정렬 메뉴는 선택 항목의 SVG 체크만 표시하고 비선택 항목의 빈 아이콘 자리에서 검은 사각형이 나타나지 않게 처리
- 로그인 헤더의 검색·언어·신고·알림·프로필을 44px 기준선으로 정렬하고 모든 메뉴 아이콘을 동일한 선형 스타일로 표시
- 언어·사용자 드롭다운은 180px 카드와 19px 고정 아이콘 열을 사용하고, 아이콘의 절대 위치·음수 여백을 제거해 아이콘과 글자가 같은 중심선 안에 표시
- 비선택 빈 아이콘은 자리 폭만 유지한 채 숨기고 기본·Hover 패딩을 고정해 경계 밖 이동 방지
- 카테고리·프로필·설정 좌측 메뉴에 행 전체 hover·키보드 focus·선택 강조와 아이콘 반응 적용
- 토론 목록 더보기는 테두리·배경·그림자 없이 세로 이클립스 아이콘만 상시 표시
- 상세 화면의 400px 토론 목록 패널을 Header 아래에서 시작하는 카드 목록으로 정리하고 6px 스크롤바 적용
- 관리자·기술지원·연구소 멤버 배지의 렌치·번개·책 아이콘을 내장 SVG로 표시
- 검색 입력 포커스의 중복 외곽선을 제거하고 부드러운 2px 단일 링만 유지
- 데스크톱 Header·목록·상세·태그·사용자 화면을 Viewport 기반 전체 폭과 동일 기준선으로 정렬
- 상세 일반 문단·목록·인용문을 Post Body 전체 폭으로 표시하고 URL·Hash·Inline Code의 영역 내 줄바꿈 적용
- Composer는 긴 문자열을 시각적으로 줄바꿈하되 저장 원문 개행은 변경하지 않음
- Code·Log Block 원문 형식과 자체 가로 Scroll 유지
- 해결 답변의 카드·상태 칩·선택 미리보기를 ABLESTACK 블루 계열로 통일
- 데스크톱 목록의 제목·카테고리·댓글 수 단일 행 배치
- 토론 목록·직접 URL에서 상세로 이동할 때 `/1` 첫 게시물부터 표시하고 지연 자동 이동 차단
- 상세 Pane 기능 버튼 상태와 무관하게 Logo를 목록과 같은 Header 좌표에 고정
- 토론 행의 더 보기 버튼 상시 표시·세로 중앙 정렬과 펼침 메뉴 레이어 보호
- 환영 영역의 위·아래 여백 대칭과 목록 아바타의 제목 중심 정렬
- 상시 표시되는 게시물 답장 아이콘과 사용할 수 없는 버튼의 비활성 상태
- Footer의 Home·Blog·Online Docs를 접근 가능한 원형 아이콘 링크로 정리
- 홈·목록·상세·검색·로그인·글쓰기·첨부 화면 정리
- 데스크톱 홈의 중복 모바일 탐색 버튼 제거와 모바일 서랍 동작 유지
- 블루 Hero·280px 메뉴·빈 상태 카드 기반 프로필 화면 통일
- 계정 설정·알림 표·보안 세션·개발자 토큰을 동일한 카드·버튼 체계로 통일
- 설정·보안 화면의 확장 기능 문구를 자연스러운 한글로 보완
- 좋아요·내 미디어·보안·해결 답변 프로필 문구 한글화
- AI 기술지원, 추가 확인 필요, 최종 해결 가이드의 상태 구분
- FoF Best Answer 사용자 화면 한글화
- FoF Best Answer 검색 상태 문구 한글화
- 모바일 44px 터치 영역, 키보드 포커스, 모션 축소 지원

운영 이상 시 확장만 비활성화하면 Flarum 기본 화면으로 즉시 복귀합니다. Core, Vendor, DB Schema는 수정하지 않습니다.
